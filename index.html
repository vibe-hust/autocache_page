Overview

AutoCache uses an AI agent to find when a model can reuse earlier calculations. After this search, the selected rule runs on its own: no retraining and no more agent calls.

Across three tested image and video models, generation is 1.99–3.14× faster than running without caching. Outputs also stay closer to the uncached results than with the compared caching methods.

Method

  1. Search. An AI agent writes and tests caching rules on a development set.
  2. Choose. Select a rule for each model and keep it fixed.
  3. Generate. NEW computes a fresh update from the model blocks. REUSE applies their saved update instead.

Both tests reuse the selected rules without another search.

FLUX3 → FLUX.1-dev: AutoCache has the best output similarity on all three metrics, with 31.64 dB PSNR at 1.96× speedup. SeaCache is faster at 2.28× among the 50-step methods.

DrawBench → GenEval 2: The same Qwen rule reaches 27.50 dB PSNR at 3.02× speedup, ahead of DiCache and SeaCache on all three similarity metrics and speed.

Test setup
  • Model transfer: The rule from FLUX3-Image-Klein-Base (5.6B, 1024 × 1024) runs unchanged on FLUX.1-dev (12B, 256 × 256), using 170 DrawBench prompts.
  • Test-set transfer: The Qwen rule found on DrawBench runs unchanged on 800 GenEval 2 prompts. Methods use matched prompts and seeds.
